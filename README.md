# 户型装修设计（floorplan-3d-pro）

> X 用户 [@akokoi1](https://x.com/akokoi1) 分享的户型设计工具的**模块化重构 Pro 版**：
> 从单个 `index.html` 迁移到 **Vue 3 + Vite + Three.js** 工程。功能、交互与外观保持一致，
> 代码按 AppShell 的区域分层（外壳 / 工作区 / 领域内核 / 状态），便于扩展（多楼层、loft 夹层、漫游、AI 助手等）。
> 单文件无需构建的版本见上级目录。

中文 | [English](README.en.md)

纯前端的户型装修设计工具：在 2D 平面图上摆放家具、拆改墙体、划分房间区域、测量尺寸，一键切换到 Three.js 3D 场景，可以鸟瞰，也可以第一人称漫游。支持多楼层与 loft 夹层、墙面材质、3D 画质档位，以及可选的 AI 设计助手。

## 功能

**2D 平面布置**
- 按户型原始比例 1:60 / 1:100 显示，尺寸单位 mm
- 缩放下限 0.004 px/mm（1px ≈ 250mm），1000px 宽的视口可一次看全约 250m —— 商场 / 厂房这类大平面也能整屏浏览；缩得很小时房间名与家具名会自动放大，保持可读
- 左侧家具库按 **住宅 / 商业 / 户外** 三个页签分组（228 种家具家电、社区配套与沙盘构件）：住宅（卧室、客厅、餐厨、卫浴、家电、书房休闲、隔断、楼层）、商业（公共、餐饮、零售）、户外（车库、运动场地、水景、儿童、景观、道路），以及地产沙盘（18/26/33F 楼栋、洋房、叠拼、别墅、商业裙楼、幼儿园、大门、入口广场、镜面水池、跌水景墙、绿化与周边建筑体量）、地库专项（地库标准模块、顶板覆土、出入口、出地面楼梯间、采光顶、风机房、防火卷帘、无障碍/子母/微型车位、减速带、广角镜、车位引导屏）与交通景观基元（4/6 车道城市道路、平交路口、红绿灯、公交站、地铁口、道闸、车棚、消防车道、回车场、隐形消防车道、无障碍坡道、园路、汀步、木栈道、旱喷、溪流、亲水平台、驳岸、景墙、雕塑、围栏、标识、草坪灯、庭院灯、榉树/乌桕/棕榈/竹丛、花境、水生植物、树阵、行道树、用地红线），以及城市背景（周边板楼/塔楼/学校/医院/商业综合体/城市路网/河流/湖泊/公园/山体/地铁线·站点/高压线/变电站）、营销展示（售楼处/样板房/看房通道/围挡/道旗/广告灯箱）、运动补充（半场篮球/门球场/轮滑场/环形健身步道/宠物乐园/老年活动场地）、地下补充（人防区域/储藏间/设备机房）与施工阶段（塔吊/基坑/施工道路/材料堆场），支持扩展自定义 3D 资产
- 内置样板：平层（四室 / 三室 / 两室 / 一室 / 单间）、独栋洋房（三层）、花园别墅（含地下车库）、loft 夹层、**商场样板（三层 · 15 间业态商铺 + 玻璃店面 + 并排电梯）**、自定义空户型
- 拖动移动、旋转（`Shift` 自由角度）、调整尺寸，贴墙 / 贴家具边线自动吸附（墙体优先）；同类家具靠近时显示虚线辅助框，并按行 / 列拉出**边框延长线**，隔得很远也能沿延长线对齐
- 画墙时同样会从附近墙体的边线 / 中线延伸出虚线辅助线，墙线自动吸附对齐（贴面优先于中线），落墙与预览完全一致
- 家具不能穿墙：落点压到墙体 / 门窗时显示红色警示框与原因，松开后自动还原
- 测量工具：靠近墙面自动吸附，`Shift` 锁定水平 / 垂直
- 工作区内**禁用浏览器原生右键菜单**，改为应用内右键菜单（见下）
- 导入户型图：选一张平面图图片，自动识别墙体与房间并生成可编辑几何

**拆改墙体 / 房间区域**
- 拆改墙体工具（`X`）：左侧面板切换为墙面组件库
  - **墙体**：非承重墙 / 承重墙，点 A → 点 B 绘制（自动 90° 正交、不出外墙，起点落在墙上会吸附墙边并垂直分叉）
  - **房间区域**：拖出矩形（或点 A、点 B）划分区域，区域内墙体门窗自动扣除，起终点吸附墙体与已有区域的顶点 / 边线，新区域必须与墙体或已有区域相连
  - **门 / 窗**：房门、入户门、双开门、推拉门、窗户、飘窗；只能开在非承重墙 / 外墙上（承重墙不可开洞），开洞会自动把墙段裁剪
- **墙面材质**：选中非承重墙后在右侧面板切换乳胶漆 / 墙纸 / 木饰面 / 瓷砖 / 石材 / 文化砖 / 玻璃；选玻璃时 3D 用「铝框 + 玻璃」隔断建模，门窗洞口上方同步补玻璃
- 墙段自动合并（延长 / 覆盖转换）、门洞删除后按原墙型补墙、材质随墙段变形跟随

**多楼层 & loft 夹层**
- 楼层管理：新增 / 删除楼层、切换当前层、把任意层设为夹层（loft）、最多 3 层地下层
- 夹层是独立平面：有自己的外墙与楼板区域，不继承一层的墙面与房间；挑空区域保留栏杆
- 一层上行楼梯（步梯 / L 型步梯 / 旋转步梯 / 扶梯 / 坡道）的占地自动在夹层楼板开洞，移动 / 旋转楼梯会同步更新
- loft 户型必须保留至少一处楼梯（最后一处不可删除 / 清空）

**3D 场景**
- 鸟瞰、斜视、俯视多种视角，点击房间列表可飞到对应房间
- 漫游模式：桌面端 `WASD` + 鼠标，触屏用虚拟摇杆；从入户门外开始，实色渲染，未铺地板的区域禁止进入，不会穿出楼板边缘
- 剖切四档：2.8m / 3.5m / 4.5m / 层高（层高档跟随当前楼层净高，切层自动更新），另有「半透明」外墙开关，便于查看户型内部
- 日照时间滑块、夜景灯光；「整栋」开关控制其它楼层实色渲染（含家具）或半透明体量；房顶 / 场地开关
- 引擎级交互：点击道闸抬杆、点击小区大门滑开、喷泉水柱脉动
- 家具弹性入场：2D→3D 或重新打开「家具」时，当前楼层家具从上方落下并在触地后回弹；数量多时在 2s 内错峰分批，渲染循环只更新已进入动画的家具
- 报告计算进 Web Worker：车位连通性 / 坡道 / 土方 / 强排指标 / 房间净面积（区域布尔）在 Worker 中完成，主线程只接收结果；Worker 不可用时自动同步降级
- 性能 HUD：视图 → 性能 → 性能 HUD，在底部状态栏显示 FPS / draw call / 三角面 / 家具 / 实例 / 墙段 / 阴影
- 季节与夜景皮肤：春花瓣 / 秋落叶 / 冬雪粒子；夜间可在树冠挂节庆串灯
- 性能：同型同色的树 / 灌木 / 车辆达到 6 件自动切 `InstancedMesh`，选中时临时实体化以保留拖动 / 旋转；逐件家具与整栋楼层仍按材质烘焙
- **画质档位（性能）**：视图菜单 → 性能 → 推荐 / 低 / 中 / 高
  - 「推荐」按当前平台与硬件（触屏、CPU 核心数、内存）自动在低 / 中 / 高里挑一档
  - 档位控制渲染像素比、抗锯齿、阴影开关与贴图分辨率、室内点光源数量、环境反射（详见下文）
- 门扇模型：入户门 / 房门（木门套、凹板、双面把手）默认打开，可点门开关；推拉门为门套 + 玻璃双扇
- 精细家具模型：柜门分缝与拉手、软包床头、带环境反射的金属与陶瓷材质等
- 在 3D 中也能选中、拖动家具，与 2D 方案实时同步
- 选中家具后出现变换 gizmo：**蓝色旋转环**（拖动旋转，吸附墙体走向 / 15° 刻度，`Shift` 自由角度）、
  **红 / 绿两根 X / Z 轴箭头**（沿轴平移，复用网格与贴墙吸附）；悬停变抓手光标，角度与位移实时显示在状态栏
- 帮助 → **模型总览**：按分类浏览家具库 2D 图例，点击在右侧 3D 预览（环绕、缩放，可开关包围盒 / 尺寸 / 自动旋转）

**右键菜单**
- 选中家具：属性 / 上下行（楼梯类）/ 顺逆时针旋转 / 复制 / 删除
- 选中房间或区域：地面材料与属性 / 删除
- 拆改模式下选中墙体或门窗：属性 / 转为承重墙·非承重墙（外墙）/ 删除
- 右键本身即「当前模式的左键命中」：选择模式选中家具 → 房间，拆改模式选中门窗 → 墙体，空白处清空选中
- 触屏长按 0.5s 等价于右键；绘制 / 测量过程中右键为取消

**属性面板**
- 房间 / 区域：名称、面积、周长、开间进深、墙面面积估算、地面材料、顶灯款式、家具清单
- 按类型区分文案与可用属性：**室内房间 / 室内区域**（计入套内、可铺地面、装顶灯）；**户外区域**（不计入套内、无天花与顶灯、地面标高 / 台地）；**飘窗**（构件，0.45m 台面）
- 地面材料分「室内 / 户外」两组，室内空间室内组优先，户外区域户外组优先
- 家具：尺寸、颜色、旋转、复制 / 删除、楼层上下行

**方案与统计**
- 房间面积与套内使用面积自动统计（楼梯洞口、挑空会从面积中扣除）
- 地面材料按面积加 5% 损耗估算造价（室内材料 / 户外铺装分别标记）
- 强排指标：按「用地红线」或场地外接范围统计用地面积，按楼栋体量层数反算总建筑面积、容积率、建筑密度与绿地率（草坪 / 花境 / 树阵 / 水生植物 / 顶板覆土），并联动车位户比；没有红线时为估算口径并在面板注明
- 车位指标与自动排车位：右键房间 / 区域 →「自动排车位」，矩形轮廓铺整块地库模块（排数随进深自适应、长边自动作为排布方向），异形 / 带洞轮廓逐位排布（只保留四角与中心都在轮廓内的完整车位，并自动补车道中心线与柱网）；右侧概览跨楼层汇总总车位 / 充电 / 无障碍 / 子母 / 微型，可填写户数并实时给出户均车位、充电与无障碍占比；「地库自检」按规则包（基础 / 标准 / 高端）提示户均配比、充电占比、无障碍车位、出入口、车道连通性（全部车位能否从出入口到达）与坡道坡度，并给出顶板覆土 / 基坑土方估算；可一键导出「指标 + 自检 + 连通性 + 坡道 + 土方」CSV 报告
- 撤销 / 重做（150 步），方案自动保存在浏览器 `localStorage`（v2：节点图存档，旧的扁平存档自动兼容读取）
- 中文 / English 界面切换（默认中文，选择会记住）
- 导出 PNG 图片；导出 / 导入方案 JSON（含所有楼层、家具、房间区域与墙体门窗，不含视图状态）
  - 文件格式 v2：自建墙 / 门窗 / 区域 / 家具以**节点图**（`nodes[levelId]`）保存，墙体是「整段 + 洞口」的语义模型，
    加载时投影回运行时数组；v1 文件与旧版裸 state 仍可导入

**AI 助手（可选）**
- 右下角 AI 面板：用自然语言让模型直接改方案（加墙、开门窗、划分区域、布置家具、切楼层…）
- 兼容 OpenAI 协议的 `/chat/completions`：DeepSeek / OpenAI / 通义 / Moonshot / 智谱 / 本地 Ollama、vLLM，填 `baseURL + model + apiKey` 即可，支持流式输出与思考模式
- 另提供本地 MCP 桥（`?agent=1` 或 `window.__plan3d.enable()` 显式开启，仅连 `127.0.0.1:4317`），便于外部 Agent / Playwright 驱动与实时预览

## 快速开始

需要 Node.js 18+，推荐使用 pnpm：

```bash
git clone <仓库地址>
cd <仓库目录>/floorplan-3d-pro
pnpm install          # 或 npm install
pnpm dev              # 本地开发服务器（默认 http://localhost:5173）
```

生产构建：

```bash
pnpm build            # 输出到 dist/
pnpm build:single     # 借助 vite-plugin-singlefile 打包成单个 HTML 文件
pnpm preview          # 预览构建产物
```

> 3D 场景依赖 [Three.js](https://threejs.org/)（已作为 npm 依赖打包，构建后无需联网）。
> AI 助手需要自备模型 API Key（在「帮助 → AI 助手配置」里填写，仅保存在本地浏览器）。

## 3D 画质档位（性能）

菜单：`视图 → 性能`。档位只影响渲染开销，不改动方案数据。

| 档位 | 像素比上限 | 抗锯齿 | 阴影 | 阴影贴图 | 白天 / 夜景点光源 | 环境反射 |
| --- | --- | --- | --- | --- | --- | --- |
| 低 | 1 | 关 | 关 | 512 / Basic | 0 / 4 | 关 |
| 中 | 1.5 | 开 | 开 | 1024 / PCF | 4 / 8 | 开 |
| 高 | 2 | 开 | 开 | 2048 / PCF Soft | 4 / 不限 | 开 |

- **推荐**不是一个独立档位：点击时按当前设备（是否触屏、CPU 核心数、`deviceMemory`）在低 / 中 / 高里挑一个直接应用，按钮上会显示建议档位。
- 切换后像素比、阴影、灯光数量、环境反射立即生效；抗锯齿是渲染器创建期参数，重新进入 3D 后按新档位生效。

## 沙盘资产规范

- **单位与朝向**：所有资产按真实 mm 建模，锚点在底面中心，正面朝 `+x`，与平面 `rotate` 一致；拖放、旋转、吸附不依赖每个资产的私有约定。
- **材质槽**：3D 按主墙 / 线条 / 玻璃 / 金属 / 屋顶 / 店招拆色，同一材质在烘焙时合并；单件资产通常 2–10 个 Mesh，几百栋楼仍是可控的 draw call 量级。
- **LOD**：2D 缩到总图档（`LOD.SITE`）时只绘制沙盘资产，室内家具不参与；3D 家具按「材质 + 阴影」烘焙。树、车这类高频重复构件目前按件烘焙，后续可切 `InstancedMesh` / billboard 进一步压缩。
- **指标同源**：楼栋层数表、地库排布、绿地类型都集中在 `core`，2D 图例、3D 建模与指标面板共用同一份数据，避免「画出来的」和「算出来的」两张皮。

## 技术栈

- **Vue 3**（`<script setup>`）+ **Pinia** 状态管理
- **Three.js** r160（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）
- **Vite 5** 构建；`vite-plugin-singlefile` 可输出单文件版本
- 2D 平面图用 **SVG** 绘制，几何布尔与面积计算为手写纯函数
- 目录按 AppShell 区域划分：`shell/` 只负责布局，`workspace/` 是内容区，`core/` 是无框架依赖的纯逻辑，`stores/` 是唯一状态来源；导入统一使用 `@/` 别名
- 中英文文案集中在 `src/i18n.js`
- 方案数据保存在浏览器 `localStorage`，启动时自动恢复

## 自定义户型

户型数据集中在 `src/core`：

- `core/plans/index.js` 的 `PLANS` 定义每个户型的静态几何（`LOFT_GEO`、`DEFAULT_GEO` 等）：墙体 `walls`、窗 `wins`、门 `doors`、推拉门 `slides`、房间 `rooms`、楼板区域 `regions`，以及地面材料 `MATS`（室内 / 户外分组以水泥地为界）与单价。
- `core/library/index.js` 的 `LIB` 定义左侧家具库分组；`core/library/furnSvg.js` 给出 2D 图例，`workspace/view3d/build/furniture.js` 给出 3D 模型；`core/library/assets/` 放以 `icon + model.js` 形式扩展的自定义资产。
- `core/library/wallItems.js` 是拆改墙体面板的组件目录，`core/library/wallMats.js` 是墙面材质目录（新增材质需同时给出 2D 填充色与 3D 材质参数）。
- 夹层的独立几何通过 `levelGeos` 指定；`geoVersion` 用于本地存档迁移（几何变更时递增，旧存档会自动重算）。
- 新增数据或组件时按层归位：纯几何 / 纯数据放 `core/`，界面放 `shell/` 或 `workspace/`，状态放 `stores/`，导入统一写 `@/...`。

修改这些数据即可换成自己的户型；新增的内置户型在 `PLANS` 中登记后，顶栏下拉即可选择。
